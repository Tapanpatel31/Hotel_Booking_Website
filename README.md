🏨 Hotel Booking Website

A modern Hotel Booking Website built with React.js as the frontend technology, styled using Tailwind CSS, and enhanced with prebuilt UI components. The application includes secure user authentication powered by Clerk, allowing users to log in and manage their profiles seamlessly.

🚀 Features

🔐 User Authentication with Clerk (Sign Up / Sign In / Sign Out)

👤 User Profile Management (Update profile details, manage account settings)

🏨 Browse Available Hotels

📅 Hotel Booking Interface

🎨 Modern UI with Tailwind CSS

📱 Fully Responsive Design

⚡ Fast and Optimized Performance with React

🛠️ Tech Stack

Frontend: React

Styling: Tailwind CSS

Authentication: Clerk

UI Components: Prebuilt Tailwind-based UI libraries

Package Manager: npm / yarn
